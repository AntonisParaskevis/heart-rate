# heart-rate
A Python script that calculates the ideal exercise heart rate of a person.

# Requirements
Python 3.x

# Download
Click the Code button, then click on "Download ZIP"

OR

Click the heart_rate.py file, then click on the Download Raw File button.

# How to Use
1. Enter the person's age. It must be a positive integer. Then, press Enter.
2. Enter the person's resting heart rate. It must be a positive integer. Then, press Enter.
3. The ideal exercise heart rate will be displayed on screen.
4. Finally, press Enter to exit the program.
